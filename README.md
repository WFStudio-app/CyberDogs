# 🐶 CyberDogs

**CyberDogs** — мультиинструментальный сетевой комбайн для **Termux** в стиле **Flipper Zero**.
Интерактивное меню в терминале телефона: сканируй сети, сигналы и Wi-Fi вокруг себя.

> ⚠️ Проект предназначен только для образовательных целей и легального
> тестирования собственных сетей. Не используйте его против чужих устройств.

---

## 📋 Возможности (текущая версия v0.1.0)

Главное меню:

```
1. Сканирование
0. Выход
```

Раздел **«Сканирование»**:

| № | Функция | Описание |
|---|---------|----------|
| 1 | Сканирование сетей вокруг | Определяет локальные подсети устройства и обходит `/24` через ping, показывая активные хосты и их имена. **Остановка по ENTER** в любой момент |
| 2 | Сканирование сигналов | Обзор радиосигналов: Bluetooth-адаптер и устройства (Termux:API), справка по доступным радиомодулям |
| 3 | Сканирование Wi-Fi вокруг | **Живой список** окружающих Wi-Fi сетей и роутеров: SSID, BSSID, уровень сигнала (dBm + шкала), защита, канал/частота, производитель роутера (по MAC-OUI). Скан повторяется циклически, новые сети помечаются `●`. **Остановка по ENTER**, затем автовозврат в меню через 5 секунд |

### Остановка сканирования (v0.3.0)

Любое сканирование в разделе «Сканирование» можно прервать в любой момент:

```
⏹  Нажмите ENTER — сканирование немедленно останавливается
↩  Показываются итоги (найденные хосты / сети)
⏱  Через 5 секунд программа автоматически возвращается в главное меню
```

В планах: пинометр портов, fingerprint-сканер, работа с Sub-GHz/NFC через внешнее железо, плагины.

## 🚀 Установка и запуск (Termux)

### 1. Установите Termux
Лучше из **F-Droid** (из Google Play — устаревшая версия):
👉 https://f-droid.org/packages/com.termux/

### 2. Скачайте CyberDogs

```bash
pkg update -y && pkg install -y git python
git clone https://github.com/WFStudio-app/CyberDogs.git
cd CyberDogs
```

### 3. Установите зависимости

```bash
bash install.sh
```

или вручную:

```bash
pkg install -y python nmap iproute2 termux-api
```

### 4. (Рекомендуется) Termux:API
Для Bluetooth/Wi-Fi-сканирования установите приложение **Termux:API**
(той же подписи, что и Termux — F-Droid / GitHub) и выдайте разрешения Android.

### 5. Запуск

```bash
python3 cyberdogs.py
```

Быстрая строка «всё в одном»:

```bash
pkg update -y && pkg install -y git python && git clone https://github.com/WFStudio-app/CyberDogs.git && cd CyberDogs && bash install.sh && python3 cyberdogs.py
```

## 🗂 Структура проекта

```
CyberDogs/
├── cyberdogs.py            # точка входа, меню
├── install.sh              # установка зависимостей для Termux
├── core/
│   └── ui.py               # баннер, цвета, меню-движок
├── modules/
│   ├── scan/
│   │   ├── networks.py     # 1. сканирование сетей (ping /24)
│   │   ├── signals.py      # 2. сканирование сигналов (BT / радио)
│   │   └── wifi.py         # 3. сканирование Wi-Fi (только Termux:API)
│   └── attack/
│       ├── wifi_crack.py   # 1. подбор пароля от Wi-Fi
│       └── hosts_crack.py  # 2–3. подбор пароля от хостов и устройств
└── wordlists/              # словари с паролями (все .txt-файлы здесь)
    ├── pn_e00001.txt       # цифры — Easy pass
    ├── pn_h0001.txt        # цифры — Hard pass (200k p)
    └── pn_ea_01.txt        # цифры + буквы
```

Добавлять новые функции просто: создайте модуль в `modules/…`
и зарегистрируйте пункт меню в `cyberdogs.py`.

## 🧨 Раздел «Подбор / Взлом» (v0.2.0)

В главном меню добавлен пункт **2. Подбор / Взлом**:

```
1. Подбор пароля от Wifi
2. Подбор пароля от Хоста
3. Подбор пароля от других устройств
← Назад
```

### 1. Подбор пароля от Wi-Fi
- Выбираете сеть из списка обнаруженных (или вводите SSID вручную);
- Затем выбираете словарь:
  | Пункт | Словарь | Описание |
  |---|---|---|
  | 1 | `wordlists/pn_e00001.txt` | Подбор из цифр — Easy pass (35 000 паролей) |
  | 2 | `wordlists/pn_h0001.txt` | Подбор из цифр — Hard pass / 200k p (50 000 паролей) |
  | 3 | `wordlists/pn_ea_01.txt` | Пароли из цифр и букв (250 000 паролей) |
- Подбор идёт **каждые 0.5 секунды** по одному паролю; прогресс, скорость и текущий пароль видны на экране; найденный пароль сохраняется в `logs/wifi_crack.log`.
- Список сетей и боевой режим работают через **Termux:API** (`termux-wifi-scaninfo` / `termux-wifi-connect`). Если Termux:API недоступен, включается безопасный демо-режим симуляции.

### 2. Подбор пароля от Хоста
Перебор паролей по **SSH** (порт 22 по умолчанию, можно менять): указывается IP/домен, логин и словарь — тот же шаг 0.5 сек. Реальные попытки идут через `paramiko`; если хост недоступен — демо-режим. Итоги: `logs/hosts_crack.log`.

### 3. Подбор пароля от других устройств
То же, но для сервисов роутеров/камер/IoT — **FTP/Telnet**-порты (21 по умолчанию), дефолтный логин `admin`.

> ⚠️ Используйте только против собственных устройств и сетей, где у вас есть разрешение. Несанкционированный подбор паролей нарушает закон.
